## 功能 1 · 市排名（力度排名 / 总榜）
- 页首 **32 城力度总榜**，可按「毕业生补贴 / 租房补贴 / 购房补贴·房票」**多选维度**，按总额或单维排名
- 城市卡片旁直接显示 **「全省 第 X / N」「全国 第 X / M」双排名**（`rk-line`）
- 点城市名 → 开详情抽屉

## 功能 2 · 区排名（区内力度排名）
- 市/区筛选器三档：**全市**（市级 + 所有区，默认）／**仅市级**／**具体区名**（市级 + 该区，因市级在该区同样适用 → 支持市区两级叠加计算）
- 区级条目带 `.dist-tag` 区名标签，**右上角序号徽标 = 该条在该城市各区中的力度排名**（`.dist-rank`，Phase 39 T4）
- 筛选器下方固定提示：「区级政策仅查阅、不计入力度排名（各区门槛口径不统一，混算会拉偏总榜）」
- 实证：若区级全计入，杭州市级-only 评分 14.0 万会被虚高到 1008.4 万

## 功能 3 · 政策溯源
- 每条政策附：`source.unit`（发文单位）+ `doc_no`（文号）+ `date`（发布日期）+ `url`（原文链接）
- 示例：临安区「生活补贴9万元」→ 杭州市临安区人社局 · 临人才办〔2023〕9号 · note 标注「市区两级叠加：市级3万+临安区级加码6万」
- 采集红线：拒收新闻门户 / 自媒体 / 本地宝，只收政府公报、红头文件；征求意见稿、已废止文件不收

## 功能 4 · 其他
- **学历筛选**：全部 / 专科 / 本科 / 硕士 / 博士，切换后索引、抽屉、对比表、总榜全联动；按学历精确匹配（选本科只看本科档，不用硕士兜底）
- **跨省对比**：任意 2–10 城并排，浙江 + 广东可混选，对比表内显示 `第 X / N` 相对排名
- **排名口径**：只算「满足学历要求即可拿」的普适金额；特定人才计划 / 需认定 / 急需紧缺目录 / 单位限定 / 高层次人才 A–E 类 / 区级 **均不计入排名**（数据保留、详情页可见）

- 宁波 / 温州 / 嘉兴 / 湖州 / 绍兴 等 30 城均有区级政策入库

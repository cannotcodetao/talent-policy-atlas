# 任务计划 · 人才政策图谱网站宣传视频

**目标**：为「人才引进政策图谱（浙江 + 广东）」网站制作 1 条视频号宣传视频，展示核心功能（市排名 / 区排名 / 政策溯源 / 学历筛选 / 跨省对比）。

## 风险与约束
- **政策时效性**：所有金额以 2026-08 采集为准，视频须带免责句（画面角标 + 简介）
- **不报金额**：口播只点名城市、不含具体金额数字；金额在画面演示中真实露出
- **数字口径（已对齐 2026-09-09）**：1436 条 / 32 城 / 12 维 / 区级 414 条（30/32 城有区级数据）
- **区级口径**：区级金额不计入城市总榜，文案不得写成「区进总榜」

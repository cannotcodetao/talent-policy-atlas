# 人才引进政策图谱（浙江 + 广东）

> 一份自包含单文件的政策对比工具：**32 城 × 12 维 × 1436 条**人才政策（含 414 条区级），全部来源为政府官网。

---

## 一、项目是什么

把分散在各地政府网站的**人才引进 + 人才安居**政策，人工逐条核实后结构化成统一格式，
再用一个网页把它们并排铺开——让你在几分钟内看清「哪个城市对我最有利」。

**打开方式**：直接双击 `人才引进政策_2026.html`（单文件、离线可用、无任何外部依赖）。

---

## 二、解决什么问题

| 痛点 | 本项目的做法 |
|---|---|
| 政策散落在几十个政府网站，找不全 | 已替你跑完 32 城，**1436 条**政策全部入库（含 **414 条**区级） |
| 新闻/自媒体转载，不敢信 | **只收政府官网**（`*.gov.cn`），每条附文号 + 原文链接可自查 |
| 只看金额会被误导（有的要认定、有的已过期） | 分层标注：普适口径评分 + 风险提示 + 时效提醒 |
| 城市之间没法横向比 | 力度总榜 + 任意 2–10 城对比表，最高值金色高亮 |
| 我是本科/硕士/博士，跟我有关的才想看 | 顶部学历筛选（专科/本科/硕士/博士），全表联动 |

## 三、功能定位

### 核心能力
1. **城市索引** — 按省份切换（浙江 11 城 / 广东 21 城），点城市名开详情抽屉
2. **力度排名** — 32 城总榜，按「毕业生补贴 + 租房补贴 + 购房补贴/房票」三维度合计排序，可点城市名直接看详情
3. **跨省对比** — 任意选 2–10 城并排，金色高亮该维度力度最高者
4. **学历筛选** — 全部 / 专科 / 本科 / 硕士 / 博士，切换后索引、抽屉、对比表、排名全部联动
5. **详情抽屉** — 单城 12 维全量政策，逐条附来源单位、文号、发布日期、原文链接
6. **市 / 区筛选 + 区内排名** — 抽屉内可切「全市 / 仅市级 / 具体区」（选区时市级政策同样适用，故市区两级可叠加查看）；区级条目右上角数字 = 该条在该市各区中的**力度排名**；30/32 城已有区级数据

### 12 个维度

| # | 维度 | 说明 |
|---|---|---|
| 1 | 毕业生补贴 | 按学历档（专科/本科/双一流/硕士/博士）的现金 + 房票 |
| 2 | 落户 | 门槛、渠道、随迁 |
| 3 | 配套保障 | 人才公寓、租房补贴、子女教育、医疗 |
| 4 | 创业扶持 | 担保贷款、一次性补贴、场地补贴、大赛资助 |
| 5 | 申报路径 | 平台、材料、流程、咨询电话 |
| 6 | 先租后售人才房 | 租期、价格基准、租金抵扣、转售条件 |
| 7 | 定向优惠价购房 | 房源项目、价格基准、优惠力度、退出约束 |
| 8 | 人才购房补贴/房票 | 金额、发放方式、约束条件 |
| 9 | 企业内部福利房 | 企业自持人才房、团购条款 |
| 10 | 高层次人才专项 | A–E 类（各地分类体系不同，保留原文本）· **仅查阅，不参与排名** |
| 11 | 时效提醒 | 申报窗口期、政策过渡期 |
| 12 | 风险提示 | 服务期、退还条款、交易限制 |

## 四、数据口径（重要）

### 来源规则
- **只收政府单位官网**：人社局、政府门户、政府公报、住建局/住保房管局、公安局、人才办、园区管委会
- **拒绝**：新闻门户、自媒体、本地宝、商业聚合站——它们只能当线索，必须追到原始文件才能引用
- 每条记录来源单位 + 文号 + 日期 + 原文 URL，可逐条自查

### 只收现行有效
- 征求意见稿 / 草案 / 未印发稿一律不收
- 已废止、过期、受理窗口已关闭且无后续兑现的，整条剔除

### 评分口径（避免被虚高金额误导）
1. **按学历精确匹配** — 选「本科」就只看本科档，不用硕士/博士档兜底，「全部」档 ≡ 本科档
2. **普适口径** — 只算「满足学历要求即可拿」的金额；特定人才计划 / 需认定 / 急需紧缺目录 / 单位限定 的金额**不计入排名**（数据保留、详情页可见）
3. **高层次人才不计入** — A–E 类、领军人才等金额不参与普通毕业生评分（独立维度仅查阅）
4. **区级政策不计入**（全库一致，Phase 38–40 已铺开）— 414 条区级政策只展示、不参与城市总榜评分，避免各区门槛口径不统一污染总榜。实证：杭州市级-only 评分 14.0 万，若区级全计入将虚高至 1008.4 万

> ⚠️ 因此某些城市总榜分数为 0 或偏低，往往是因为当地补贴**全部依赖急需紧缺目录或特定计划**——属口径内正常结果，不是漏采。

## 六、怎么更新

### 改一条政策
1. 找到源头：`浙江 → zhejiang-talent-data.json`；`广东 → guangdong_raw/<拼音>.json`
2. 改完跑下面三条：

```bash
python _build_combined_data.py   # 源头 → talent-data.json
python _build_html.py            # → 人才引进政策_2026.html
python _validate_compliance.py   # 须 0/0/0
```

### 回归五件套（任何改动后都跑）
```bash
python _validate_compliance.py                 # ① 合规 0/0/0
python _validate_multi.py                      # ② 结构 11/11
python _validate_redesign.py                   # ③ 视觉 ALL PASS
NODE_PATH="C:/Users/24237/.workbuddy/binaries/node/workspace/node_modules" \
  "C:/Users/24237/.workbuddy/binaries/node/versions/22.22.2-2/node.exe" _test_multi.js   # ④ jsdom 18/18
NODE_PATH="C:/Users/24237/.workbuddy/binaries/node/workspace/node_modules" \
  "C:/Users/24237/.workbuddy/binaries/node/versions/22.22.2-2/node.exe" _test_district.js # ⑤ 区级筛选 11/11
```
